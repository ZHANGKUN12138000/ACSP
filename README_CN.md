# Cylinder Surface Pattern（Abaqus/CAE 2020）

这是一个面向三维实体零件的 Abaqus/CAE GUI 插件。它从完整、1/2 或 1/4 的圆柱面、圆锥面以及光滑变半径旋转面生成新的结果零件，不修改源零件。

## 功能

- 巧克力式刻槽：行、列表示最终露出的弧面凸块数量，例如 5 行 × 4 列会留下 20 个凸块，并在凸块之间切出 4 道连续横向沟和 3 道连续纵向沟；变半径曲面上的沟底会跟随旋转母线。
- 两种刻槽构造：既可直接切入源零件副本，也可保持原表面完整，在其外侧增加一层“已经刻槽的凸起弧面方块”；两种方式都只作用于拾取的局部面。
- 平行外衬：刻槽操作可先在所选旋转面外侧增加指定厚度的连续外衬。外衬沿局部法线等距生成并跟随圆柱、圆锥或光滑变半径母线；直接切槽模式从外衬表面向内切，凸起模式把刻槽方块放在外衬外侧。
- 局部面片：取消默认铺满选项后，纹理尺寸由凸块尺寸和沟宽共同决定，只覆盖拾取面内的一块局部区域；母线偏移和角向偏移可调整位置。
- 铺满与端部留白：默认自动反算凸块尺寸，使凸块与沟槽均匀覆盖“所选面减去两端留白”的范围。`Un-grooved margin at each meridian end` 分别在母线两端保留同样距离。
- 复杂旋转件：可直接拾取已经切分出来的局部旋转面。例如先把哑铃中段分成单独面，再只选中段；如果外侧仍是一个连续面，也可用较大的两端留白把刻槽限制在中部。
- 方块附着：法向厚度、母线方向长度和圆周方向宽度可分别输入，不再局限于正方块；可选择对齐、奇偶圈半间距交错，或每一圈继续累加指定角度的渐进错位。
- 小球附着：可输入小球直径和行列数，选择对齐、奇偶圈半间距交错（紧密排列），或逐圈角向错位。
- 多层覆盖：方块和小球均可沿曲面法向生成多层，并选择层间直接堆叠或相邻层在两个曲面方向上交错。悬空模式的首层仍与源表面保持指定正间隙。
- 变半径均匀排布：每一圈都按该处真实局部半径单独换算角间距，圆锥和哑铃形曲面不再因统一角度步长而在大半径处被拉稀。
- 自动覆盖：勾选 `Automatically calculate rows/columns to fill the picked face` 后，行列输入被忽略，插件根据所选面尺寸、方块边长/球直径和排列方式计算能够完整放入的最大行列数。
- 悬空覆盖：勾选 `Detached cover` 后，方块或球沿曲面局部法线保持输入间隙，不接触源旋转体；结果仍放在同一个新 Part 中，但每个悬空体保持独立 cell。
- 不切分旋转体：方块/球体操作不再创建任何行列基准面切分；嵌入模式合并时也删除内部交界，只保留一个干净的连续实体域。
- 自动网格：可输入全局网格尺寸、Abaqus/Standard 或 Abaqus/Explicit 单元库以及单元/网格类型。

可选网格类型：

1. 扫掠六面体 C3D8R（默认；巧克力沟槽会自动生成轴向扫掠层）
2. 自由四面体 C3D4
3. 自由二次四面体 C3D10
4. 自由修正四面体 C3D10M

圆柱巧克力沟槽会在横沟边缘和凸块中部生成母线方向扫掠层，不创建任何包含旋转中轴线的径向分割面，避免中心附近出现小单元。标准圆柱沟槽默认保持扫掠 C3D8R。方块/球体、变半径面以及带台阶的复杂旋转体通常不可可靠扫掠；任何六面体请求一旦失败，插件都会清除失败网格、保留已经生成的几何并自动重试自由 C3D4，不再因“无法扫掠”删除输出结果。

## 安装

将整个 `CylinderSurfacePattern` 文件夹复制到 Abaqus 2020 的插件搜索目录之一，例如：

```text
C:\SIMULIA\CAE\plugins\2020\CylinderSurfacePattern
```

也可以放到用户插件目录（若不存在可新建）：

```text
%USERPROFILE%\abaqus_plugins\CylinderSurfacePattern
```

重新启动 Abaqus/CAE 2020。在菜单中打开：

```text
Plug-ins -> Cylinder Surface Pattern -> Grooves / packed bodies...
```

## 使用步骤

1. 在 Part 模块打开一个三维可变形实体零件。
2. 启动插件，填写 Model、Source part 和 New output part。
3. 在顶部 `1 Basic / Operation` 标签页选择刻槽、方块或小球。
4. 打开动态显示的 `2 Groove Settings` 或 `2 Cube / Sphere Cover` 标签页，只输入当前操作相关的参数。
5. 在 `3 Mesh / Output` 标签页输入网格参数和输出选项。
6. 点击 Continue。
7. 在视口中只选一个圆柱/圆锥/变半径旋转外表面，点击 Done。
8. 插件创建并显示一个新的结果零件，同时在装配中保留结果实例。

结果零件中会创建集合 `CSP_ALL_CELLS`。源零件不会被修改。如果输出名已经存在，默认停止；只有勾选 overwrite 后才会删除同名旧输出及其装配实例。

## 参数说明与约束

- `Raised-block rows/columns` 是沟槽之间保留下来的凸块数量，不是独立凹坑数量。
- `Groove construction` 选择 `Cut grooves into source body` 时使用沟深；选择 `Add raised grooved blocks` 时源表面保持完整，使用凸起刻槽层厚度。
- `Parallel outer liner thickness` 为 0 时不生成外衬；大于 0 时生成与所选面平行的连续等距外衬。
- `Block meridian length` 与 `Block circumferential width` 控制每个弧面凸块的尺寸。
- `Transverse groove width` 沿旋转母线量取；`Longitudinal groove width` 是参考半径处的圆周弧长。
- 沟深沿所选旋转面的局部外法线计算。
- `Patch meridian offset` 和 `Patch angular offset` 将局部巧克力面片从所选面的中心移动；偏移进入端部留白或越界时会停止并提示。
- 默认铺满模式下，手动凸块尺寸和两个偏移值不参与计算；只需输入凸块行列数、横纵沟宽和沟深。
- 如果选择的是已经切分出来的局部旋转面，所有沟槽都限制在该面范围。
- 方块/小球为“紧密堆积面片”，整体在所选面上居中；方块的法向厚度、母线长度、圆周宽度分别对应三个局部方向。尺寸和数量放不下时插件会停止并提示。
- `Ring / row arrangement` 的渐进模式按“第 1 圈 0°、第 2 圈 +输入角度、第 3 圈 +2×输入角度……”累加；局部非完整圆周面会自动限制偏移，避免附着体越过面边界。
- `Number of normal layers` 控制法向层数；`Stagger adjacent layers` 会将奇数层沿圆周及母线各偏移半个间距，边缘处只保留完整落在所选面范围内的附着体。
- `Interface embed fraction` 是附着体沿局部法线向曲面内微量嵌入的比例，用来形成有效布尔连接，建议保留默认值 `0.05`。
- `Detached surface clearance` 仅用于悬空覆盖，必须大于零；它是附着体最近表面与所选曲面之间的法向距离。
- 自动覆盖只放置能够完整落在所选面参数范围内的规则网格，不会裁切边缘处的方块或球。
- 请选择 Part 上下文中的几何面，并确保对话框里的模型名和零件名与当前显示对象一致。
- 所选面必须是绕同一轴旋转得到、两端具有圆形边界且母线沿轴向单调的单个外表面。圆柱、圆锥和光滑哑铃形母线均支持；球面、任意自由曲面、母线回折的旋转面不支持。

```text
cylinderSurfacePattern_plugin.py   # 菜单注册入口
```

## 兼容性

源码严格使用 Python 2.7 语法，目标版本为 Abaqus/CAE 2020。开发验证还使用了 Abaqus/CAE 2022 的同代 Python 2.7 内核。

版本 1.0.1 同时兼容单个 `Face`、`FaceArray`、元组和列表形式的视口拾取结果，修复 Abaqus 2020 单面拾取时报 `object of type "Face" has no len()` 的问题。

版本 1.1.0 将独立矩形凹坑改为局部巧克力式连续横纵沟槽，新增凸块尺寸与面片位置控制。

版本 1.2.0 默认使用扫掠六面体 C3D8R；巧克力刻槽不再沿圆柱中轴线切分，并新增默认铺满所选面的均匀反算模式。

版本 1.3.0 修复插件第二次打开时复用失效 AFX 步骤导致的 CAE 闪退；新增圆锥/光滑变半径旋转面、母线两端留白和局部中段刻槽；方块/球体或变半径面在默认六面体不可扫掠时会自动回退到 C3D4。

版本 1.4.0 增加阶梯旋转体六面体失败后的通用 C3D4 重试；方块/球体不再切分旋转体或保留内部合并边界；新增按所选面自动计算行列数以及带正间隙、不接触曲面的悬空覆盖模式。

版本 1.5.0 将过大的单页对话框改为顶部标签页；刻槽与方块/球覆盖参数按操作动态互斥显示，并继续根据铺满、手动和悬空状态隐藏当前不生效的输入项。

版本 1.5.1 在标签页外增加固定高度的右侧纵向滚动区域；内核的 29 个 GUI 参数全部提供兼容默认值，并在插件初始化时重载内核，修复旧 GUI 会话创建球体时报 `takes exactly 29 arguments (22 given)` 的问题。

版本 1.6.0 修正圆锥/变半径曲面覆盖在不同半径处疏密不一的问题；方块新增独立母线长度与圆周宽度；方块/球新增对齐、奇偶交错、逐圈累加角度以及多层直接/交错堆叠；刻槽新增“保留原表面并附加凸起刻槽块”和与所选面平行的连续外衬。全部 37 个参数保持默认值，仍兼容旧会话的 22 参数调用。
